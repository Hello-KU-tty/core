# Evidence Analyst v1.0.6: clean semantic acceptance boundary

This revision is a source and fixture regression, not a live model result. The fixture is synthetic, contains no personal data, and does not establish human learning.

Prompt v1.0.6 separates requests, explanations, predictions, reasoned choices and performed applications. A request alone yields no Proposal. A `REPHRASE` can support at most `EXPLAINED`; an independent strong `PREDICTION` retains the existing policy rather than receiving a blanket cap. A future plan or conditional remedy is not an `APPLICATION`. A reasoned project choice can support `DEMONSTRATED` only when the same selection has a structured `USER_DECISION` source with user-authored rationale. A user source that directly reports an already performed project action and observed result remains eligible for `APPLICATION`; this records a natural-language self-report and does not independently attest that the action occurred.

The regression fixture preserves two historical failures as negative boundaries: an explanation must not become `JUSTIFIED_DECISION`, and a future validation rule must not become `APPLICATION/DEMONSTRATED`. Existing accepted Evidence and derived state are not rewritten or counted as success.

The clean personalization plan uses a four-cell Helper comparison: curated Ledger off/on crossed with recent Episodes off/on. All cells must use the same question, current Project context, prompt version, model ID and host settings. The curated Ledger item is one independently authored `REPHRASE/EXPLAINED` item whose exact text, Signal, dependence and State are accepted through a new in-memory Application integration test. That deterministic acceptance is not a live Analyst result or human-learning claim. The recent Episode contains no accepted Evidence and includes a Helper-supplied conclusion whose near-repeat would be `DIRECTLY_LED`. Deterministic checks verify toggles and provenance; a human reviewer judges whether the clean Ledger produces a useful difference and whether recent conversation is kept distinct from curated Evidence. A separate unseen Discovery pair toggles only the clean Ledger and never injects recent Episodes.

No native Analyst or Helper model call has been run for this revision. A future live run must record the actual model/configuration for every paired cell and must not infer model compliance or user learning from the fixture alone.
