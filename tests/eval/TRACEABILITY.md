# MVP acceptance criterion 추적표

T18 시점의 평가는 계약·품질 실패 검출 기반, 실제 Candidate Agent 회귀, phase별 Discovery/Spec과 target latency 회귀, Builder Decision 수직 흐름, bounded Helper 대화, hidden no-tool Evidence Analyst→Core 적용, 실행 가능한 Campus Drop Golden Path와 optional Final Upgrade를 포함한다. 아래 `현재 근거`는 완료된 검증만 뜻하며, 전체 제품 수직 흐름 완료 판정은 `최종 검증` 작업에서 수행한다.
