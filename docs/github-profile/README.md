# Hello Vibe

만들면서, 이해의 근거를 남기는 Kiro 기반 바이브코딩 개발 환경.

코딩 초보자가 배우고 싶은 기술에서 자기에게 필요한 TypeScript 프로젝트를 발견하고, Builder와 실제로 완성하며 Helper에게 필요한 설명을 받습니다. Agent가 작성한 코드와 사용자가 직접 설명·판단한 근거를 구분해 다음 설명과 프로젝트 추천에 활용합니다.

[다운로드·설치](https://github.com/Hello-KU-tty/core/blob/main/docs/DOWNLOAD_GUIDE.md) · [시연 영상](https://github.com/Hello-KU-tty/core/blob/main/docs/assets/vibe-helper-demo.mp4) · [검증 범위와 한계](https://github.com/Hello-KU-tty/core/blob/main/docs/VALIDATION_STATUS_20260930.md)

| 저장소 | 역할 |
| --- | --- |
| [core](https://github.com/Hello-KU-tty/core) | TypeScript Core, SQLite, 역할별 MCP·권한, Agent prompt, 설치·검증 |
| [program](https://github.com/Hello-KU-tty/program) | Kiro 확장 frontend: Discovery·Spec·Builder·Helper·History |

Windows x64와 Apple Silicon Mac의 설치 안내는 다운로드 가이드에서 확인하세요. Intel Mac은 지원하지 않습니다. 프로젝트 상태는 로컬에 저장되며 모델 사용량은 본인의 Kiro 계정에서 차감됩니다.

실제 사용 후 정성 인터뷰를 진행했습니다. 이를 정량 학습 향상이나 일반 Kiro 대비 우월성의 증명으로 주장하지 않습니다. 설치·자동 검사와 실제 모델 전체 흐름은 검증 기록에서 구분합니다.
