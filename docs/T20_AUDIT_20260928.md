# T20 보안·개인정보·접근성·복구 감사

기준:2026-09-28 19:06 KST. 이번 수정은 모델0이며, 실제 프론트 소스와 bounded Mac 개발 host를 검증했다. Windows 전용 검증은 사용자 제외 범위다. 이 문서는 penetration test, 전체 WCAG 인증, 일반 제품 설치 인증 또는 T20 전체 완료 선언이 아니다.

## 수정과 재현

- 첫 Discovery 입력 전에 Activity 기본 활성화, local SQLite/생성 코드 저장, 모델에 필요한 입력·코드 문맥 전달, redaction 한계, reset/export·자동 삭제 미제공을 알린다. 새 동의 모달이나 탐색 단계는 추가하지 않았다. 해당 범위는 SPEC7.2의 post-MVP 운영 결정을 유지한다.
- 한국어 HTML에 `lang=ko`, 학습 목표에 안내 `aria-describedby`, 스크롤 가능한 Builder/Helper/저장 대화/도구 출력에 이름 있는 `region`과 `tabindex=0`을 적용했다. 상태의 polite live region과 오류 alert는 유지하며 매 token을 낭독시키지 않는다. CSS·색상·레이아웃을 변경하지 않았다.
- 실제 renderer에서 후보 바구니 선택 후 hydration이 버튼 DOM을 교체해 초점이 BODY로 빠지는 문제를 Chrome에서 재현했다. 표시 데이터가 같으면 DOM을 유지하고 선택/busy 상태만 갱신한다. 상세화로 재생성할 때는 같은 Project/session의 같은 후보·동작이 존재하고 활성화된 경우에만 초점을 복원하며 입력창의 초점을 빼앗지 않는다.4개 회귀 중 수정 전3 FAIL을 확인했고 전체719 tests와 실제 Chrome Space→선택 후 focus→Tab/Enter·다듬기 초안 보존을 통과했다. 이 브라우저 검사는 실제 renderer와 명시된 모델0 transport fixture이며 native 실행으로 세지 않는다.
- 과거 Mac 실험의 계정별 경로 literal은 OS 홈+동일 고정 하위 경로로 계산한다. legacy persistent receipt는 Mac으로 제한하고 `/private/tmp` prefix의 `..`/중복 separator/비정규 철자를 거절한다. 소유자/canonical/권한 및 packaged gate를 완화하지 않으며 Trust는 새로 주지 않는다. receipt3·기존 invoke probe2·relay6 회귀 PASS다.
- UI/Agent/분석의 schema 검증된 구조화 텍스트는 저장 전에 기존 redactor를 거쳐 같은 schema로 다시 검증된다. 경로 참조는 다른 파일로 redirect하지 않고 민감 내용이 있으면 거절한다. redaction으로 서로 다른 요청이 같아져도 원래 요청의 SHA로 idempotency 충돌을 판정한다. 기존 DB는 자동 수정·삭제하지 않는다.
- 긴 credential은 기존 storage guard가 `UNSAFE_PAYLOAD`로 거절했던 것이며 기존 DB 유출을 확인한 것은 아니다. 새 경계는 짧은 credential/경로도 가리고 안전하게 저장 가능한 입력을 처리한다. file-backed SQLite bytes, History/restored snapshot, 원본 입력 불변성, 재시작 replay, Agent provenance와 길이 재검증을5개 회귀로 확인했다.
- native TEXT와 runtime SSE에서 한 글자씩 분할한 합성 secret이 연결되면 노출되는2개 FAIL을 재현했다. 64자 look-behind(더 긴 workspace root는 그 길이)와 미완성 민감 구간을 보류한다.65,536자 넘는 미완성 구간은 해당 turn의 TEXT를 fail-closed 처리한다. 오류/취소는 꼬리를 폐기하고 정상 종료는 가린 뒤 flush한다. 상태·도구 이벤트는 계속 전달한다.
- 모든2분할/문자별, Bearer/assignment/known token/PEM/인용된 공백 경로/긴 workspace root/일반 streaming/상한/취소의17개 stream 검사를 추가했다. 경로 뒤 정상 텍스트가 사라지는 기존 adapter 회귀도 수정하고 전체 테스트를 다시 통과했다. 정규식 redaction은 임의 개인정보나 모든 표현을 탐지하는 DLP가 아니다.
- 결과 실행기는 매번 manifest/path를 재검증하고 컴파일 출력/package/lock의 bounded fingerprint가 바뀌면 자신이 소유한 child만 교체한다. 최대4096개 항목/64MiB, 파일·symlink·경로 경계8개 회귀를 통과했다. 생성 코드의 OS sandbox를 새로 제공한 것은 아니다.
