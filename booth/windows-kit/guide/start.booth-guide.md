# ① 처음부터 만들어 보기

배우고 싶은 기술 하나로, 그 기술이 꼭 필요한 프로젝트를 찾아 직접 만들어 봐요.

1. **왼쪽 Vibe Helper 패널**에 배우고 싶은 것을 적고 후보를 찾아요. 30초~1분쯤 걸려요.
   - 예: `여러 명이 동시에 신청해도 정원이 넘치지 않게 만드는 법`
   - 예: `로그인한 사람만 자기 메모를 볼 수 있게 만드는 법`
2. 마음에 드는 후보를 고르면 **내가 이해할 것**과 **AI가 맡을 것**이 정리돼요. 괜찮으면 **이걸로 시작**.
3. **오른쪽 Kiro 채팅**에서 AI가 실제로 만들기 시작해요. 정해야 할 것이 생기면 번호로 물어봐요.
   - **번호와 이유를 한 문장으로** 답해 주세요. 내 말로 쓴 이유가 이해의 근거로 남아요.
   - 명령을 실행해도 되는지 물으면 내용을 보고 허락해 주세요.

> 만드는 데 몇 분 걸려요. 기다리기 어려우면 바탕화면의 **② 결정하는 순간 체험하기**도 해 보세요.
>
> 다 쓰셨거나 막히면 Kiro 창을 닫고 바탕화면 아이콘을 다시 누르세요. 처음부터 시작돼요.
